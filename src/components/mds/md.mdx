# Overview

**SWIFT** (*Simple Weighted Intrinsic Feedback Technique*) learns a reward function directly from a task-performing LLM’s **intrinsic signals** (hidden states or logits). This enables efficient **Best-of-N** selection without relying on a massive text-based reward model.

## Motivation

Best-of-N sampling is typically bottlenecked by conventional reward models:

- **Massive**: often a fine-tuned LLM with billions of parameters.
- **Costly**: training and inference are GPU-heavy.
- **Data-hungry**: requires large-scale preference data.

SWIFT bypasses these issues by mining the task LLM’s own internal signals.

## Method (high-level)

1. For each generated token, extract hidden states from selected transformer layers (or use final logits in logits-only mode).
2. Feed token features into a lightweight linear reward model with an optional gating mechanism.
3. Aggregate token-level scores into a single reward for each candidate response, then select the best candidate in Best-of-N.

## Key Features

- **Extreme efficiency**: orders of magnitude smaller than LLM-based reward models.
- **Strong performance**: competitive or better Best-of-$N$ accuracy on standard benchmarks.
- **Data efficiency**: works well with only a few thousand training samples.
- **Flexible signals**: supports hidden states (open models) and logits-only settings.
